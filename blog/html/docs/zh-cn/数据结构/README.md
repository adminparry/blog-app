# 数据结构

<div class="ds-markdown ds-markdown--block" style="--ds-md-zoom: 1.143;"><p class="ds-markdown-paragraph">数据结构是计算机中存储、组织数据的方式，通常分为<strong>线性结构</strong>和<strong>非线性结构</strong>两大类。以下是常见的数据结构分类和示例：</p><hr><h3><strong>一、线性数据结构</strong></h3><p class="ds-markdown-paragraph">数据元素按顺序排列，只有一个前驱和一个后继（除首尾元素）。</p><ol start="1"><li><p class="ds-markdown-paragraph"><strong>数组（Array）</strong></p><ul><li><p class="ds-markdown-paragraph">连续内存存储，固定大小，支持随机访问。</p></li><li><p class="ds-markdown-paragraph">变体：动态数组（如C++的<code>vector</code>、Python的<code>list</code>）。</p></li></ul></li><li><p class="ds-markdown-paragraph"><strong>链表（Linked List）</strong></p><ul><li><p class="ds-markdown-paragraph">非连续内存，通过指针连接，灵活大小。</p></li><li><p class="ds-markdown-paragraph">类型：单链表、双链表、循环链表。</p></li></ul></li><li><p class="ds-markdown-paragraph"><strong>栈（Stack）</strong></p><ul><li><p class="ds-markdown-paragraph">后进先出（LIFO），操作：<code>push</code>、<code>pop</code>。</p></li><li><p class="ds-markdown-paragraph">应用：函数调用栈、表达式求值。</p></li></ul></li><li><p class="ds-markdown-paragraph"><strong>队列（Queue）</strong></p><ul><li><p class="ds-markdown-paragraph">先进先出（FIFO），操作：<code>enqueue</code>、<code>dequeue</code>。</p></li><li><p class="ds-markdown-paragraph">变体：双端队列（Deque）、优先队列（Priority Queue）。</p></li></ul></li><li><p class="ds-markdown-paragraph"><strong>哈希表（Hash Table）</strong></p><ul><li><p class="ds-markdown-paragraph">键值对存储，通过哈希函数快速查找。</p></li><li><p class="ds-markdown-paragraph">冲突解决：链地址法、开放寻址法。</p></li></ul></li></ol><hr><h3><strong>二、非线性数据结构</strong></h3><p class="ds-markdown-paragraph">数据元素之间存在多层次或复杂关系。</p><ol start="1"><li><p class="ds-markdown-paragraph"><strong>树（Tree）</strong></p><ul><li><p class="ds-markdown-paragraph">层次结构，每个节点有零或多个子节点。</p></li><li><p class="ds-markdown-paragraph">常见类型：</p><ul><li><p class="ds-markdown-paragraph">二叉树（Binary Tree）：每个节点最多两个子节点。</p><ul><li><p class="ds-markdown-paragraph">变体：二叉搜索树（BST）、AVL树、红黑树（自平衡树）。</p></li></ul></li><li><p class="ds-markdown-paragraph">堆（Heap）：完全二叉树，用于优先队列。</p></li><li><p class="ds-markdown-paragraph">Trie（前缀树）：用于字符串检索。</p></li></ul></li></ul></li><li><p class="ds-markdown-paragraph"><strong>图（Graph）</strong></p><ul><li><p class="ds-markdown-paragraph">由顶点（Vertex）和边（Edge）组成，表示任意关系。</p></li><li><p class="ds-markdown-paragraph">类型：有向图、无向图、加权图。</p></li><li><p class="ds-markdown-paragraph">存储方式：邻接矩阵、邻接表。</p></li></ul></li></ol><hr><h3><strong>三、其他特殊数据结构</strong></h3><ol start="1"><li><p class="ds-markdown-paragraph"><strong>并查集（Disjoint Set）</strong></p><ul><li><p class="ds-markdown-paragraph">管理不相交集合，支持合并与查询。</p></li></ul></li><li><p class="ds-markdown-paragraph"><strong>跳表（Skip List）</strong></p><ul><li><p class="ds-markdown-paragraph">多层链表，优化有序数据的搜索效率。</p></li></ul></li><li><p class="ds-markdown-paragraph"><strong>布隆过滤器（Bloom Filter）</strong></p><ul><li><p class="ds-markdown-paragraph">概率型数据结构，高效判断元素是否存在（可能有误判）。</p></li></ul></li><li><p class="ds-markdown-paragraph"><strong>B树/B+树</strong></p><ul><li><p class="ds-markdown-paragraph">多路平衡树，用于数据库和文件系统索引。</p></li></ul></li></ol><hr><h3><strong>四、选择数据结构的依据</strong></h3><ul><li><p class="ds-markdown-paragraph"><strong>访问方式</strong>：随机访问（数组） vs 顺序访问（链表）。</p></li><li><p class="ds-markdown-paragraph"><strong>插入/删除频率</strong>：链表更高效，数组需移动元素。</p></li><li><p class="ds-markdown-paragraph"><strong>内存效率</strong>：连续存储（数组） vs 指针开销（链表、树）。</p></li><li><p class="ds-markdown-paragraph"><strong>应用场景</strong>：</p><ul><li><p class="ds-markdown-paragraph">快速查找：哈希表、BST。</p></li><li><p class="ds-markdown-paragraph">层次关系：树。</p></li><li><p class="ds-markdown-paragraph">网络关系：图。</p></li></ul></li></ul><p class="ds-markdown-paragraph">理解不同数据结构的特性和适用场景，是优化算法和系统设计的关键！</p></div>
